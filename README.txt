WHY THE VIDEO AREA IS NOT FAKE
I could not reliably identify TORSI's actual YouTube channel/video IDs from public web results, so the page deliberately does NOT invent an ID.
The page contains a YouTube search link and a clearly marked embed location. Once you have a video URL, replace the placeholder with:
https://www.youtube.com/embed/VIDEO_ID

PERSONAL PHOTOS
No personal TORSI artist photographs were available as actual image files in the accessible project/library assets. I have therefore not fabricated or substituted a fake artist photo. The design instead uses the real TORSI logo and the real Spotify embed, which supplies Spotify's current artwork automatically.
